Inter — font utama (body, UI, dan judul admin) starter v2.0-next.

Sumber   : Google Fonts, keluarga "Inter" versi v20
Diambil  : 2026-09-14 dari fonts.googleapis.com/css2?family=Inter:wght@100..900
Berkas   : Inter-latin.woff2, Inter-latin-ext.woff2
           Keduanya font VARIABEL — satu berkas melayani bobot 100-900.
Lisensi  : SIL Open Font License 1.1 (OFL) — boleh dipakai, disematkan, dan
           didistribusikan ulang, termasuk komersial.
           https://fonts.google.com/specimen/Inter/license

Subset   : HANYA latin dan latin-ext. Subset cyrillic, cyrillic-ext, greek,
           greek-ext, dan vietnamese tidak dipakai starter ini dan cuma
           menambah unduhan.

Alasan self-host, bukan menautkan ke Google Fonts: CSP proyek ini `font-src 'self'`,
dan panel admin tidak perlu memanggil server pihak ketiga setiap kali dibuka.

Memperbarui: ambil ulang CSS-nya dengan User-Agent peramban modern (kalau tidak,
Google mengirim format lama), lalu unduh URL woff2 subset latin dan latin-ext.
unicode-range di theme.css ikut disalin dari CSS itu kalau berubah.
